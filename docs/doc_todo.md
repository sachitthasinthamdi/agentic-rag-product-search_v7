## B. ต้องเพิ่มใหม่ ไม่มีในเล่มเลย

### B1 · หัวข้อใหม่ "ตรวจสายพานทั้งเส้น" — วางก่อนหรือใน `## ข้อค้นพบหลัก`

ของดี (ป้าย ≥ 2) ตายที่ชั้นไหน กลุ่มที่คลังมีของ 71 คำค้นต่อภาษา

| ชั้น | ไทย | อังกฤษ |
|---|---|---|
| ค้นไม่เจอใน 100 อันดับ | 16 (5.9%) | 18 (6.6%) |
| ตกที่กฎตัดทิ้ง | 0 | 0 |
| ตกที่ประตูคัด | 16 (5.9%) | 17 (6.2%) |
| **ตกที่การจัดอันดับ** | **131 (48.2%)** | **123 (45.2%)** |
| ตกที่ตัดร้านซ้ำ | 3 | 2 |

ใช้ของที่ค้นเจอแล้วได้แค่ **67% ของเพดาน** · ตัวจัดอันดับทำของหายมากกว่า
ทุกชั้นอื่นรวมกัน 8 เท่า และพังเท่ากันทั้งสองภาษา

### B2 · ข้อค้นพบใหม่ "ตัวจัดอันดับคือคอขวด และแก้ได้ด้วยสัญญาณที่ขาดไป"

- ปรับน้ำหนัก 4 สัญญาณเดิมไม่ช่วย (ไทย 0.5846 → 0.5847 · อังกฤษ 0.5614 → 0.5754)
- เพิ่มคำซ้อนเป็นสัญญาณที่ 5 → **+4.5 จุด p = 0.0005** บนกองที่จำกัดเฉพาะของมีป้าย
- ยืนยัน end-to-end ที่แขน A1 ซึ่งได้แค่สัญญาณนี้ **คลังมีของ +3.5 · มีงบจำกัด +3.4**

### B3 · ข้อค้นพบใหม่ "ให้ agent ช่วยจัดอันดับด้วย LLM ไม่ได้ผล"

หลักฐานชิ้นที่สามว่าโมเดล 8B ตัดสินความตรงไม่ได้ (ต่อจาก κ 0.08-0.25 ของ
LLM-as-judge และ self-refine ที่ล้มเหลว)

สองทางที่ลองแล้วไม่ผ่าน

1. **ให้ agent ดันน้ำหนักคำซ้อนเมื่อผลไม่ตรง** — ดัน 20 · 40 · 100 **ได้ลำดับเท่ากันเป๊ะ**
   เพราะ RRF ใช้แค่อันดับ ไม่ใช้ค่าดิบ จึงอิ่มตัว · และ `word_match` ต่ำแปลว่า
   **ของในกองไม่มีคำที่ผู้ใช้ขอตั้งแต่แรก** จัดอันดับใหม่เสกของที่ไม่มีขึ้นมาไม่ได้
2. **ให้ agent บอกว่าข้อกำหนดข้อไหนที่ผลลัพธ์ยังไม่ตอบ** แล้วถ่วงคำนั้นหนัก —
   ทำให้**แย่ลง** คลังมีของ −1.3 · มีงบจำกัด −3.1 จุด · โมเดลทิ้งคำที่ควรเก็บ
   (`gowdy` = แบรนด์) และเก็บคำที่ไม่ใช่ข้อกำหนด
   🔑 ฝั่งโค้ดหาคำที่ขาดได้ **73-83% ของคำค้น แม่นกว่าฝั่ง LLM**

**เส้นฐานที่ทำให้แยกผลได้สะอาด** ก่อนแก้ ทั้งสามแขนได้เลขเท่ากันเป๊ะทุกทศนิยม
ในกลุ่มที่คลังมีของ → ส่วนต่างที่โผล่หลังแก้คือ ข ล้วน ๆ

### B4 · `### การติดป้ายความตรงของสินค้า` (บรรทัด 375) — เพิ่ม 3 เรื่อง

1. **pooling bias** เปลี่ยนตัวจัดอันดับ → คำค้นเดิม กอง 100 ชิ้นเดิม แต่ **3 อันดับแรก
   เปลี่ยนไป 51 จาก 80 คำค้น** ของที่โผล่ใหม่ไม่มีป้าย ต้องติดเพิ่ม **86 คู่** (Zobel 1998)
2. **กฎแยกป้าย 2 กับ 1** ที่ตกลงกันระหว่างตรวจ
   - 2 = สินค้า**ชนิดเดียวกัน** ผิดคุณสมบัติ 1 อย่าง (ยี่ห้อ สี วัสดุ ขนาด ความจุ)
   - 1 = สินค้า**คนละชนิด** แต่อยู่ในเรื่องเดียวกัน
3. **การปิดตา** ไฟล์ป้ายชุดใหม่ไม่บอกว่าแขนไหนหยิบ และเรียงด้วยแฮช

🔑 ต้องเขียนด้วยว่า **การแก้ป้ายไม่ได้เอื้อฝ่ายใด** — กดตัวเลขทุกแขนลงพอกัน
และกลุ่มที่ agentic ชนะไม่ขยับเลย (p = 0.0156 เท่าเดิม)

## C. `### ข้อจำกัด` (บรรทัด 771) — เพิ่ม 3 ข้อ

1. **ปรับจูนบนชุดทดสอบ** น้ำหนัก 6 ของสัญญาณคำซ้อนเลือกจากการกวาดค่าบนป้าย
   ชุดเดียวกับที่ใช้รายงานผล ไม่ได้แบ่งชุดพัฒนา/ชุดทดสอบ
2. **ค่าที่วัดบนกองจำกัด** ตัวเลข +4.5 มาจากกองผู้เข้าชิงที่จำกัดเฉพาะของมีป้าย
   (3-10 ชิ้นต่อคำค้น) ไม่ใช่กองจริง 100 ชิ้น · ค่า end-to-end จริงคือ +3.4 ถึง +3.5
3. **ป้าย 86 คู่ชุดใหม่ไม่มีผู้ติดป้ายคนที่สอง** ต่างจากชุดเดิมที่วัด κ ไว้
   (ผู้วิจัยตรวจทุกคู่ และแก้ 5 คู่ แต่ยังไม่ได้วัดความสอดคล้องกับคนที่สอง)
4. **ฝั่งไทยไม่ได้ประโยชน์จากสัญญาณคำซ้อน** เพราะนับคำซ้อนกับ**คำแปล**
   ถ้าแปลเพี้ยน สัญญาณก็เพี้ยนตาม — ความผิดพลาดของชั้นแปลไหลลงมาทำลายสัญญาณปลายน้ำ
