สคริปต์อ่านจาก `eval/results/` กับ `eval/labels/` โดยตรง **ไม่มีค่าไหนพิมพ์มือ**

รันทุกตัว:

```bash
for f in eval/verify/*.py; do .venv/Scripts/python.exe "$f"; done
```

## ⚠ ก่อนจะแก้ตัวเลขในเล่ม

ถ้า `check_doc.py` บอกว่าค่าไหนไม่ตรง **ให้หาสคริปต์ที่ผลิตเลขนั้นมารันซ้ำก่อน**
เคยเกิดขึ้นแล้ว (`docs/steps.md` ข้อ 219): `17.3%` กับ `33/250` ดูไม่ตรงเพราะสคริปต์ตรวจ
ไม่ได้ตัดคำตอบ `weak` ออก ขณะที่สคริปต์เดิมตัด — **ที่ผิดคือสคริปต์ตรวจ ไม่ใช่เล่ม**

ตัวหารที่ต้องระวัง

| ตัวชี้วัด | ตัวหารที่ถูก |
|---|---|
| สัดส่วนภาษาและช่องเหตุผลว่าง | บรรทัดของคำตอบที่**ไม่ใช่** `weak` (รอบ 3 = 750 · รอบ 4 = 747) |
| ป้าย ข | จำนวนข้อ × 2 (กองเต็ม = 98) · คิดจากเศษส่วน ไม่ใช่ค่าที่ปัดแล้ว |
| nDCG | ระบบในอุดมคติ `[3,3,3]` = 6.3928 ไม่ใช่กองป้าย |
